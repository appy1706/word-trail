# Word Trail

A daily vocabulary trail for ISEE prep. Each child reviews a small set of new words as flashcards
(meaning, similar word, sample sentence, prefix/root/suffix clues), then a quiz unlocks that only uses words
already reviewed. Missed words come back more often. Parents can follow progress.

Quiz questions follow the three ISEE verbal formats:
- Synonyms: one word, four single-word choices
- Sentence completion: one blank
- Paired words: two blanks, four pairs of words (available for most Upper-level words)

## Put it on GitHub Pages
1. Create a new public repository (or open the one you already use).
2. Upload every file in this folder to the repository root and replace the old ones
   (index.html, words.js, manifest.json, sw.js, icon-192.png, icon-512.png).
3. Settings > Pages > Deploy from a branch > main > / (root).
4. Open the Pages address on each device. On a phone: Share > Add to Home Screen (iPhone) or Install app (Android).

First launch asks for a 4-digit PIN for the parent and each child. Progress is saved in the browser on each device.
After an update, reload the page twice so the new files replace the cached ones.
